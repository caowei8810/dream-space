## 阶段 B：用户端 MVP

### 目标

跑通以下最小闭环：

```text
灵感列表 -> 灵感详情 -> 登录 -> 创建会话 -> 提交任务
-> Worker 模拟生成 -> SSE 返回进度 -> 展示结果 -> 下载
```

管理端同期只实现登录、灵感管理和任务查询。模型结果先使用可重复的模拟数据，避免真实供应商接入阻塞业务开发。
