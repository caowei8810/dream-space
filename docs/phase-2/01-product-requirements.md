# Phase 2 产品需求

## 1. 产品目标

Phase 2 建设造梦空间的商用运营能力，使平台能够管理前台注册用户、控制内容风险、配置模型、统一计费、销售套餐、分析经营情况，并安全清理过期数据。

## 2. 用户管理

- 前台注册用户自动进入后台用户列表；后台支持新增、查询、编辑、停用、恢复和可恢复注销。
- 查看用户状态、注册/登录信息、会话、任务、图片、审核记录、风险命中、现金余额、套餐额度、订单和流水。
- 支持限制生成、封禁、解封和撤销会话；封禁后禁止登录、上传和生成，解封后恢复。
- 敏感词或风控规则可触发拒绝、限制、封禁或人工复核；每次处置保存规则版本和原因。
- 手机号、提示词、图片等敏感数据按角色脱敏；所有写操作调用真实 API 并写审计。

用户注销不直接删除订单、流水、审核证据和法定保留数据；物理删除由数据生命周期任务执行。

## 3. 审核管理

- 自动审核覆盖提示词、参考图、生成结果和公开灵感，风险类别至少包含涉黄、涉敏、暴恐、违法、未成年人、版权/肖像和垃圾滥用。
- 自动结果分为通过、拒绝和需要人工复核；审核服务异常时进入隔离或人工队列，不静默放行。
- 保存审核引擎、规则版本、风险码、置信度和响应摘要。
- 人工审核支持领取、转派、批量处理、通过、拒绝、下架、恢复、升级和备注，防止并发覆盖。
- 申诉包含提交、初审、复审和最终结论；复审人不能是原决定人，高风险解封支持双人审批。

## 4. 配置管理

### 4.1 模型配置

- 管理模型目录、供应商模型 ID、能力、比例、分辨率、生成张数、默认参数、状态和前台可见范围。
- 管理供应商连接引用、超时、限流、重试、健康检查、路由、灰度、熔断和降级；密钥不返回浏览器。
- 配置采用草稿、校验、审批、发布和回滚；任务保存当时的模型与参数快照。

### 4.2 敏感词和提示词风控

- 配置黑名单、白名单、词组、正则、风险分类、优先级、适用范围、有效期和命中动作。
- 命中动作支持提示、拒绝、限制生成、封禁和进入人工审核。
- 支持用户、设备、IP 频控、重复内容拦截和人工抽检比例。
- 规则初筛后可调用大模型结合完整提示词判断语义风险；保存模型、提示版本、判断结果和置信度。
- 规则支持测试样例、命中预览、灰度、审批发布和回滚，禁止直接编辑线上值。

## 5. 计费管理

- 标准批价为每张图片 `0.10 元`，以分为最小货币单位存储，不使用浮点数结算。
- 活动可在标准价基础上配置折扣，例如五折；包含活动编码、范围、开始/结束时间、优先级、叠加策略和状态。
- 最终价格由服务端计费引擎计算，同一张图片只产生一个最终价格；前端只展示服务端报价。
- 每次任务保存标准价、活动、计费规则版本和最终单价快照，后续改价不影响历史任务。
- 未购买套餐时，按最终价格从现金余额实时扣除；余额不足则整次请求拒绝。
- 任务入队前原子预扣，成功后结算，入队失败、生成失败、取消或审核拒绝后释放/返还。
- 同一幂等键不能重复扣款；并发请求不能产生负余额、负套餐额度或超卖。

默认消费顺序为：即将过期的套餐额度优先，套餐不足部分使用现金余额补扣。产品负责人变更该策略时必须更新本文件并增加兼容迁移。

## 6. 套餐管理

- 自定义套餐配置名称、编码、售价、包含图片张数、有效期、模型/分辨率权益、并发限制、每日上限、排序和状态。
- 例如 `10 元 / 800 点`：后台生成关联套餐的兑换码，用户在账户设置中兑换后创建套餐权益快照并增加 800 点可用额度。
- 每成功生成一张图片消费一次套餐额度；多图任务按图片张数预扣和结算。
- 历史订单保存购买时的套餐版本和权益快照；后续修改套餐不改变已有权益。
- 套餐额度与现金余额分账，不相互伪造换算；退款、过期、赠送、补偿和人工调整均写不可变流水。
- 兑换码必须关联套餐版本、一次性兑换并支持禁用；站外支付平台后续通过预留接口触发发码，不实现站内支付。

## 7. 运营管理

- 运营总览展示今日生图量、成功率、平均/P95 时延、队列积压、待审核量、用户增长、用户分布、收入、退款、模型成本和风控命中。
- 支持今日、昨日、近 7 天、近 30 天及自定义时间窗口；指标标注口径和更新时间并跳转到明细。
- 用户分布至少包含新老用户、活跃度、地域/注册渠道（有合法数据时）和付费分层。
- 收入包含套餐收入、单次计费收入和退款，不把未支付订单计入收入。
- 公告支持草稿、发布、下线、展示范围、开始/结束时间和用户端读取状态。

## 8. 灵感精选

- 所有公开灵感均来自用户已经生成且审核通过的图片，不允许后台独立新建图片型灵感。
- 运营人员从用户生成结果中挑选，查看原用户、任务、提示词摘要、模型和审核结果。
- 允许补充标题、分类、排序和展示说明，然后发布、下架或恢复。
- 发布只改变精选元数据和公开状态，不复制、伪造或切断原始图片来源。

## 9. 系统管理

- 管理员工号、账号、角色、权限点、账号角色、角色权限和管理员会话。
- 系统配置包含真实外围服务连接、功能开关、上传限制、并发、维护模式和审核阈值；业务运行时不使用 mock 服务。
- 定时任务管理包含 Cron、启停、立即执行、上次/下次运行、租约、耗时、结果、重试和日志。
- 数据清理覆盖过期任务、生成图、参考图、临时对象、会话事件和验证码；使用 dry-run、分批、幂等、引用保护和可恢复窗口。
- 账务流水、支付记录、审核/申诉证据和审计日志采用独立保留策略，不能按普通图片周期删除。
