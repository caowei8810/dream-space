## 2. 用户注册与处置

```text
前台验证码登录
  -> 新用户创建 / 老用户登录
  -> 后台用户列表可见
  -> 风控或人工处置
     -> 正常：允许登录和生成
     -> 限制：允许登录，禁止上传和生成
     -> 封禁：撤销会话，禁止登录、上传和生成
  -> 解封：允许重新登录
```

## 3. 提示词风控与审核

```text
提交提示词
  -> 本地敏感词/正则/频控规则
  -> 必要时大模型语义判断
  -> 通过：进入计费预扣
  -> 可疑：建立审核案例，等待人工处理
  -> 拒绝：不调用生成模型，记录命中与用户处置
```

生成后的图片再次执行输出审核；未通过审核的图片不可交付、下载或进入灵感精选。

## 4. 计费与生成

```text
用户提交 N 张图片
  -> 服务端报价（标准价/活动价）
  -> 选择即将到期的套餐权益
  -> 套餐不足部分计算现金金额
  -> 单事务原子预扣套餐额度与现金
  -> 预扣成功后创建任务并入队
  -> 每张成功：结算对应额度/金额
  -> 失败、取消、审核拒绝：释放未消费预扣
```

任何一步重复执行必须通过幂等键返回原结果，不得重复扣款。

## 5. 套餐购买

```text
选择套餐
  -> 创建订单并保存套餐快照
  -> 支付成功回调（幂等）
  -> 创建用户套餐权益
  -> 增加可用图片张数
  -> 后续任务按到期时间优先消费
```

## 6. 灵感精选

```text
用户生成图片审核通过
  -> 进入可精选结果池
  -> 运营查看原任务和审核证据
  -> 补充展示元数据
  -> 发布到用户端灵感页
  -> 下架/恢复保留完整历史
```
