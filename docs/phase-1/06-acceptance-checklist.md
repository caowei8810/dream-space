# 阶段 1 验收清单

## 1. 产品范围

- [x] `S1-SCOPE-01` 普通用户一级导航只有灵感和生成。
- [x] `S1-SCOPE-02` 原型中没有视频、音乐、数字人、画布和资产库入口。
- [x] `S1-SCOPE-03` 用户发布、关注、评论、充值和会员不在产品路径中。
- [x] `S1-SCOPE-04` 产品名称统一为“造梦空间 / Dream Space”。

## 2. 灵感页

- [x] `S1-INS-01` 不同宽高比图片形成稳定瀑布流。
- [x] `S1-INS-02` 分类切换具有清晰选中状态。
- [x] `S1-INS-03` 搜索可以产生正常、无结果和清空状态。
- [x] `S1-INS-04` 点击图片进入对应详情。
- [x] `S1-INS-05` 悬停操作不遮挡主要图片内容。
- [x] `S1-INS-06` 返回列表后保留搜索、分类和滚动位置规则已定义。

## 3. 灵感详情

- [x] `S1-DETAIL-01` 大图保持原始比例且不拉伸。
- [x] `S1-DETAIL-02` 作者、描述、提示词、模型、比例和清晰度齐全。
- [x] `S1-DETAIL-03` 上一个、下一个和末端禁用规则明确。
- [x] `S1-DETAIL-04` 详情页默认纯查看，点击做同款后当前页展开输入器并带入提示词与参数。
- [x] `S1-DETAIL-05` 用作参考图在当前页展开输入器，同时带入图片、提示词与参数，参考图可删除。
- [x] `S1-DETAIL-07` 详情页发送后才进入生成页，未点击复用动作时不显示输入器。
- [x] `S1-DETAIL-06` 访客触发保护动作后可登录并恢复意图。

## 4. 生成页

- [x] `S1-GEN-01` 可新建、切换、重命名和删除会话。
- [x] `S1-GEN-01A` 点击新对话只展示空白创作态；首次提交后才创建会话并从提示词生成名称。
- [x] `S1-GEN-02` 输入器支持提示词和最多 4 张参考图。
- [x] `S1-GEN-03` 模型、比例、清晰度和张数均有明确选项。
- [x] `S1-GEN-04` 提交禁用条件和可见原因已定义。
- [x] `S1-GEN-05` 排队、生成中、成功、部分成功、失败和取消均有状态设计。
- [x] `S1-GEN-06` 成功结果支持下载、再次生成、修改提示词和参考复用。
- [x] `S1-GEN-06A` 生成结果支持点击预览和下载，下载失败可重试。
- [x] `S1-GEN-07` 失败状态保留原始参数并提供恢复动作。
- [x] `S1-GEN-08` 刷新和切换会话时的草稿保留规则明确。
- [x] `S1-GEN-09` 输入器空闲收起、编辑展开，且与时间线分区，不遮挡生成历史。
- [x] `S1-GEN-10` 参数面板覆盖 9 种比例、2K/4K、1-8 张并联动最终像素尺寸。

## 5. 登录与额度

- [x] `S1-AUTH-01` 手机号、验证码、协议和错误状态完整。
- [x] `S1-AUTH-02` 登录成功后不会自动消耗额度。
- [x] `S1-AUTH-03` 登录取消时不丢失来源和草稿。
- [x] `S1-QUOTA-01` 输入器显示预计消耗与剩余额度。
- [x] `S1-QUOTA-02` 额度不足时禁止提交并给出调整方式。
- [x] `S1-QUOTA-03` 未登录不显示账户额度；登录后账户菜单显示余额、总量、百分比和色条，退出后隐藏。

## 6. 视觉与响应式

- [x] `S1-UI-01` 结构与参考截图一致：窄一级导航、图片优先、底部输入器。

- [x] `S1-UI-03` 控件、标题和长提示词不存在溢出或遮挡。
- [x] `S1-UI-04` 桌面端 1440px、1280px 与移动端 390px 布局规则明确。
- [x] `S1-UI-05` 键盘焦点、图标名称、对比度和减少动画规则明确。
- [x] `S1-UI-06` 桌面一级导航无重复“我的”，左下角账户 Dock 与菜单定位正确。
- [x] `S1-UI-07` 桌面左下角使用设置图标，账户菜单提供语言与浅色/深色/跟随系统切换。

- [x] `S1-UI-09` 深色模式参数选中态、发送按钮和文本均满足可读性与对比度要求。
- [x] `S1-UI-10` 隐藏滚动条但保留滚动能力，输入器和内容区无遮挡。

## 8. 阶段完成门槛

阶段 1 完成需要满足：

1. 所有清单项目有明确结论；不适用项必须记录原因，不能直接忽略。
2. 三条核心路径均可在原型中走通：做同款、参考图生成、直接生成。
3. 所有页面异常状态都有用户可执行的恢复动作。
4. 产品负责人确认后，页面结构和核心业务规则才可在阶段 2 中变更。
