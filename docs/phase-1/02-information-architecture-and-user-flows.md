# 信息架构与用户路径

## 1. 信息架构

```text
造梦空间
├── 灵感
│   ├── 推荐/人像/摄影/动漫/插画/设计
│   ├── 搜索结果
│   └── 作品详情
│       ├── 做同款
│       └── 用作参考图
├── 生成
│   ├── 新对话
│   ├── 历史会话
│   ├── 任务详情
│   └── 图片预览
└── 账户
    ├── 登录
    ├── 平台协议
    ├── 外观与语言
    ├── AI 水印
    ├── 登录后额度
    └── 登录/退出
```

## 2. 路由

| 路由 | 页面 | 访问权限 |
|---|---|---|
| `/` | 重定向至灵感页 | 公开 |
| `/inspiration` | 灵感瀑布流 | 公开 |
| `/inspiration/:id` | 灵感作品详情 | 公开 |
| `/generate` | 新生成会话 | 登录 |
| `/generate/:sessionId` | 历史生成会话 | 所属用户 |
| `/login` | 登录 | 公开 |

查询参数用于临时传递搜索、分类和来源；提示词、参考图和生成参数使用短期草稿状态传递，不直接暴露在 URL 中。

## 3. 核心用户路径

### 3.1 从灵感做同款

```text
打开灵感页
-> 浏览或搜索作品
-> 打开作品详情
-> 点击做同款
-> 当前详情页展开底部输入器
-> 自动填入提示词、模型、比例与清晰度
-> 用户修改提示词
-> 点击发送
-> 未登录则登录并恢复草稿
-> 进入生成页并提交
-> 查看生成状态和结果
```

### 3.2 使用灵感图作为参考

```text
作品详情
-> 点击用作参考图
-> 当前详情页展开底部输入器
-> 原图成为第一张参考图
-> 提示词与参数同步带入
-> 用户可删除参考图或修改提示词
-> 点击发送
-> 未登录则登录并恢复草稿
-> 进入生成页并提交
```

### 3.3 直接创建图片

```text
点击生成
-> 未登录则进入登录
-> 新对话
-> 展示空白创作状态和提示词建议
-> 输入提示词/上传参考图
-> 选择模型、比例、清晰度和张数
-> 提交
-> 首次提交时创建并命名会话
-> 排队
-> 生成中
-> 成功/部分成功/失败
-> 下载、修改或再次生成
```

### 3.4 恢复历史任务

```text
进入生成页
-> 选择历史会话
-> 定位最近任务
-> 查看参数和结果
-> 再次生成或修改提示词
```

会话时间线独立保存。切换会话时，后台任务完成结果必须写回发起任务的原会话；点击历史会话时恢复该会话全部提示词、参数、状态和图片。

### 3.5 登录意图恢复

```text
触发受保护动作
-> 保存来源 URL、草稿、参数、参考图引用和动作
-> 登录
-> 验证保存内容仍有效
-> 返回来源或生成页
-> 自动恢复但不自动消耗额度
```

### 3.6 登录与额度

```text
未登录打开账户菜单
-> 显示登录入口，不显示额度
-> 完成登录
-> 账户菜单显示创作额度与退出登录
-> 生成完成后余额更新
-> 退出登录
-> 隐藏额度并恢复登录入口
```

## 4. 返回与关闭规则

- 灵感详情关闭后恢复列表筛选、搜索词和滚动位置。
- 灵感详情初始不显示输入器；切换上/下一个作品时重新回到纯查看状态。
- 浏览器后退与页面关闭按钮结果一致。
- 从详情进入生成后，浏览器后退回到原详情，不丢失列表上下文。
- 登录取消时返回来源页面，不清空用户草稿。
- 生成页切换会话时保存当前未提交草稿；返回该会话时恢复。
- 点击新对话只进入空状态，未提交前不在最近会话中新增记录。

## 5. 移动端结构

- 顶部保留搜索与页面级操作。
- 底部固定导航包含灵感、生成、我的。
- 灵感使用双列瀑布流；详情使用全屏图片加底部抽屉。
- 生成历史侧栏改为抽屉；输入器保持底部但随键盘安全上移。
