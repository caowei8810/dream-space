# 造梦空间产品需求文档

## 1. 文档信息

| 项目 | 内容 |
|---|---|
| 产品名称 | 造梦空间 |
| 英文名称 | Dream Space |
| 文档阶段 | 阶段 1：需求固化与交互原型 |
| 状态 | 已固化，进入阶段 2 前需通过验收 |
| 目标平台 | 桌面 Web 优先，兼容移动 Web |

## 2. 产品定义

造梦空间是面向中文用户的文生图创作平台。产品围绕“发现灵感、复用灵感、提交生成、管理生成结果”建立最短路径。

```text
灵感瀑布流 -> 作品详情 -> 做同款/用作参考图 -> 图片生成 -> 预览与下载
```

## 3. 产品目标

- 用户进入产品后可以立即浏览高质量图片，不需要先理解复杂模型参数。
- 用户可以从任意灵感作品一键进入生成，而不是手动复制全部参数。
- 生成过程以会话时间线呈现，历史提示词、参数、状态和结果可追溯。
- 界面保持克制、清晰和图片优先，降低非创作功能的干扰。

## 4. 固定产品范围

### 4.1 包含

- 灵感图片瀑布流、分类和搜索。
- 灵感作品详情、点赞、下载和提示词复制。
- 做同款和用作参考图。
- 文本生成图片、文本加参考图生成图片。
- 模型、比例、清晰度和生成张数设置。
- 生成任务状态、结果预览、重试和下载。
- 新建会话、历史会话、重命名和删除。
- 登录、退出、额度展示和登录后意图恢复。

### 4.2 不包含

- 视频、音乐、数字人和动作模仿。
- 画布、图层、局部重绘和专业图片编辑。
- 用户资产库入口。
- 用户发布、关注、评论和私信。
- 活动中心、技能市场、会员、充值和支付。

## 5. 用户角色

### 5.1 访客

- 可以浏览灵感列表、搜索、筛选和查看作品详情。
- 触发点赞、下载、做同款、用作参考图或生成时进入登录流程。
- 登录完成后恢复原页面、提示词、参数、参考图和待执行动作。

### 5.2 登录用户

- 拥有访客全部能力。
- 可以提交生成任务、查看额度、保存会话和下载图片。
- 只能查看和操作属于自己的会话、任务和生成图片。

### 5.3 运营管理员

- 不进入普通用户界面。
- 运营后台属于后续阶段，阶段 1 只定义普通用户体验。

## 6. 功能需求

### 6.1 全局导航

- 左侧固定窄导航，只显示品牌标识、灵感、生成、额度、通知、个人账户和折叠菜单。
- 灵感与生成必须保持稳定位置，不因页面内容变化移动。
- 当前模块使用实心图标和文字强调，其他模块使用线性图标。
- 桌面端保留文字标签；移动端改为底部导航，仅保留灵感、生成和我的。

### 6.2 灵感页

- 默认进入“推荐”，顶部提供推荐、人像、摄影、动漫、插画、设计分类。
- 搜索支持主题、画面描述、风格和提示词关键词。
- 图片使用紧密瀑布流，保持原始宽高比。
- 卡片悬停显示作者、点赞数和“做同款”，不遮挡主体区域。
- 点击图片主体进入详情；点击做同款直接进入生成页并带入参数。
- 页面滚动接近底部时加载下一页，加载期间显示与卡片比例匹配的骨架块。
- 无结果时显示清空搜索和返回推荐操作。

### 6.3 灵感详情页

- 中间区域展示原比例高清大图，图片不得被拉伸。
- 右侧展示作者、描述、日期、AI 标识、提示词、模型、比例、清晰度和点赞数。
- 支持关闭详情、上一个、下一个、点赞、下载、复制提示词、做同款和用作参考图。
- 底部生成器默认填入当前提示词和参数。
- 做同款保留提示词、模型、比例和清晰度，不自动加入当前图片。
- 用作参考图保留提示词和参数，并加入当前图片作为第一张参考图。
- 关闭详情后回到原瀑布流位置，不重新滚动到顶部。

### 6.4 生成页

- 左侧二级侧栏提供新对话和历史会话。
- 主区使用按日期分组的时间线展示用户请求和生成任务。
- 底部输入器包含参考图、提示词、生成模式、模型、比例、清晰度、张数和提交按钮；输入器位于页面 Grid 的独立底部区域，不以浮层遮挡任务时间线。
- 输入器空闲且无内容时收为紧凑单行；获得焦点、存在提示词或参考图、打开参数面板时自动展开；宽度按扣除一级导航和会话侧栏后的可视区域计算。
- 提示词为空且没有参考图时，提交按钮禁用。
- 参考图最多 4 张，支持 JPG、PNG、WebP；产品规格限制单张不超过 10MB。
- 支持智能、21:9、16:9、3:2、4:3、1:1、3:4、2:3、9:16 比例，2K/4K 清晰度和 1-8 张结果，并实时展示最终输出宽高。
- 提交后立即插入任务占位，显示排队或生成中状态。
- 成功结果支持预览、下载、再次生成、修改提示词和用作参考图。
- 失败结果保留原提示词和参数，提供再次生成和反馈入口。
- 删除会话需要二次确认；删除后选中最近一个会话，没有历史时进入新对话。

### 6.5 登录页

- 提供手机号验证码登录，第三方登录位置作为可配置能力保留。
- 用户提交验证码前必须同意用户协议、隐私政策和 AI 功能使用协议。
- 显示验证码错误、过期、频繁获取和网络异常状态。
- 登录成功后优先恢复触发登录前的目标动作。

### 6.6 额度

- 左侧导航展示剩余额度。
- 提交前展示本次预计消耗；额度不足时禁止提交并说明原因。
- 失败任务是否返还额度由真实计费规则决定，界面必须展示最终结算结果。

## 7. 核心业务规则

| 规则 | 定义 |
|---|---|
| 登录拦截 | 只拦截产生用户数据或消耗资源的操作 |
| 意图恢复 | 登录后恢复来源页面、提示词、参数、参考图和动作类型 |
| 做同款 | 复制提示词与生成参数，不带原图片 |
| 用作参考图 | 复制提示词与参数，并带入原图片 |
| 再次生成 | 使用原任务参数创建新任务，不覆盖旧任务 |
| 修改提示词 | 把原任务内容放回输入器，用户确认后再提交 |
| 会话命名 | 首次提交后取提示词前 20 个中文字符，可手动修改 |
| 删除 | 会话删除需要确认；任务和单图不提供独立删除入口 |
| 图片标识 | 生成图片在展示和下载时保留 AI 生成标识策略 |

## 8. 产品数据与指标

- 灵感曝光、详情打开、搜索、分类切换。
- 做同款点击、参考图点击、登录拦截与登录恢复成功。
- 任务提交、生成成功、生成失败、再次生成和下载。
- 从灵感详情到任务提交的转化率。
- 生成成功率、平均排队时间和平均生成时间。

阶段 1 只定义事件名称和触发点，不实现统计系统。

## 9. 产品约束

- 产品使用独立品牌和原创演示素材，不复刻即梦 Logo、营销文案和作品素材。
- 灵感与生成是唯一普通用户一级业务模块。
- 任何新增功能不得破坏“图片优先”和“最短生成路径”。
- 桌面端主要适配宽度为 1280px 以上；移动端最低支持 360px。
