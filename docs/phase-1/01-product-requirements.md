# 造梦空间产品需求文档

## 1. 文档信息

| 项目 | 内容 |
|---|---|
| 产品名称 | 造梦空间 |
| 英文名称 | Dream Space |
| 文档版本 | v1.1，高保真原型评审基线 |
| 文档阶段 | 阶段 1：需求固化与高保真交互原型 |
| 状态 | 原型已完成多轮评审，可作为阶段 2 开发输入 |
| 目标平台 | 桌面 Web 优先，兼容移动 Web |

## 2. 产品定义

造梦空间是面向中文用户的文生图平台，围绕“发现灵感、复用灵感、提交生成、管理结果”建立最短创作路径。

```text
灵感瀑布流 -> 作品详情 -> 做同款/用作参考图 -> 确认输入 -> 图片生成 -> 预览与下载
```

产品参考成熟 AI 图片创作工具的交互效率，但使用独立品牌、视觉系统、产品文案和工程实现。

## 3. 产品目标

- 用户进入后立即看到高质量图片，不需要先理解模型参数。
- 用户可以从灵感作品复用提示词、模型、比例、清晰度和参考图。
- 生成过程以会话时间线保存，提示词、参数、状态和图片结果可追溯。
- 灵感详情以看图为第一目标，只有用户主动复用作品时才展示输入器。
- 界面保持克制、图片优先、无多余滚动条和无关业务入口。
- 浅色、深色、跟随系统和中英文界面具备一致的可用性。

## 4. 固定产品范围

### 4.1 包含

- 灵感图片瀑布流、分类、随机排序、搜索和搜索历史。
- 灵感作品详情、点赞、下载、提示词复制、做同款和用作参考图。
- 纯文本生成图片，以及“文本 + 参考图”生成图片。
- 模型、比例、清晰度、生成张数和预计额度设置。
- 新对话空状态、历史会话、会话重命名、删除和结果恢复。
- 生成任务状态、结果预览、单图下载、再次生成和修改提示词。
- 手机号验证码登录、退出、协议查看、账户设置和登录状态保持。
- 创作额度、预计消耗、余额比例和低余额状态。
- 中文/英文、浅色/深色/跟随系统主题。
- 桌面 Web 与移动 Web 响应式体验。

### 4.2 不包含

- 视频、音乐、数字人和动作模仿。
- 画布、图层、局部重绘和专业图片编辑。
- 用户资产库和素材管理入口。
- 社区发布、评论、私信和完整关注关系。
- 活动中心、技能市场、会员、充值和支付。
- 运营后台的正式实现。

> 灵感详情中的作者关注可作为高保真视觉占位，阶段 1 不建设关注数据关系和关注列表。

## 5. 用户角色

### 5.1 访客

- 可以浏览灵感、搜索、筛选和查看作品详情。
- 可以在详情页展开做同款或参考图输入器，修改提示词和参数。
- 提交真实生成、点赞、下载或保存用户数据时进入登录流程。
- 登录完成后恢复来源页面、草稿、参数、参考图和待执行意图。

### 5.2 登录用户

- 拥有访客全部能力。
- 可以提交生成任务、查看额度、保存会话和下载图片。
- 只能查看和操作自己的会话、任务、参考图和生成图片。
- 账户菜单显示创作额度和退出登录；退出后隐藏额度并恢复登录入口。

### 5.3 运营管理员

- 不进入普通用户界面。
- 阶段 1 只定义普通用户体验；管理端正式需求基线见 [管理端产品需求](../admin-console-requirements.md)，功能架构见 [管理端功能架构](../admin-console-architecture.md)。
- 管理端必须通过独立会话和服务端 RBAC 访问，不能由前台页面权限推导管理员权限。

## 6. 功能需求

### 6.1 全局框架

- 桌面端使用 72px 固定窄导航，只保留品牌、灵感、生成、通知和设置。
- 灵感与生成保持稳定位置，不因页面内容变化移动。
- 不在一级导航重复展示“我的”，也不在导航中展示额度卡。
- 移动端使用底部导航，包含灵感、生成和我的。
- 顶部工作台信息可包含随机励志语、日期、天气和语言入口；内容保持简洁，不抢占图片主视觉。
- 顶部语言菜单支持中文和英文，切换后静态界面、动态菜单、空状态和生成状态同步更新。
- 页面不显示系统原生滚动条，但必须保留键盘、触控板和触摸滚动能力。

### 6.2 灵感页

- 默认进入“推荐”，提供推荐、人像、摄影、动漫、插画、设计分类。
- 当前高保真素材基线为 52 张：人像 12、摄影 10、动漫 8、插画 11、设计 11。
- 每次进入灵感页重新随机排列当前作品，并尽量避免首张与上次相同。
- 搜索支持主题、描述、风格和提示词关键词。
- 搜索框聚焦后展示最近搜索；历史去重、最近优先、最多 8 条、支持清空并在本地保存。
- 图片使用紧密瀑布流并保持原始比例，桌面多列、移动双列。
- 卡片悬停显示作者、点赞数和做同款，不进行导致布局跳动的缩放。
- 点击图片主体进入详情；卡片快捷做同款遵循详情复用规则。
- 无结果时提供清空搜索和返回推荐。

### 6.3 灵感详情页

- 主区域展示原比例高清大图，不拉伸、不裁掉主体。
- 右侧展示作者、作品描述、来源/日期、AI 标识、提示词、模型、比例、清晰度和点赞数。
- 支持关闭、上一个、下一个、点赞、下载、复制提示词、做同款和用作参考图。
- 初次打开详情时不显示底部输入器，图片同步放大并使用更多可视空间。
- 点击做同款后，在当前详情页底部展开输入器，带入提示词、模型、比例和清晰度，不带原图。
- 点击用作参考图后，在当前详情页底部展开输入器，同时带入提示词、参数和当前图片。
- 参考图缩略图必须提供可见删除按钮；删除后立即更新草稿和提交条件。
- 用户可在详情页修改提示词，点击发送后才进入生成页。
- 关闭详情后恢复原列表的分类、搜索词和滚动位置。

### 6.4 新对话与生成页

- 生成页包含会话侧栏、连续创作画布、顶部搜索/筛选和底部自适应输入器。
- 初始“最近”列表为空，不预置虚假历史会话。
- 点击新对话只进入空白创作状态，不立即创建会话记录。
- 空白创作状态展示品牌文案和 3 个高质量提示词建议；点击建议只填入草稿。
- 用户首次提交生成时才创建会话，会话名称取提示词前 14 个中文字符或前 28 个英文字符，过长显示省略号。
- 同一会话内再次生成不重复创建会话。
- 会话支持选中、重命名和删除；操作图标尺寸统一。
- 生成完成后，会话显示首张结果缩略图。
- 每个会话保存独立时间线；切换后恢复历史提示词、参数、状态和图片。
- 生成过程中切换会话，任务完成后仍写回原会话。
- 删除当前会话后打开下一条；没有其他会话时回到新对话空状态。
- 生成顶部搜索点击后在原位置横向展开，点击外部或按 Esc 收回并清空临时筛选词。
- 时间、模型和操作状态筛选必须可用，并与当前语言同步。

### 6.5 生成输入器与参数

- 输入器处于页面 Grid 的独立底部区域，不遮挡时间线。
- 新对话空状态下输入器使用完整展开形态；普通会话中空闲可收起，聚焦、有内容、有参考图或参数面板打开时展开。
- 输入器宽度根据扣除一级导航和会话侧栏后的可视区域计算。
- 提示词为空且没有参考图时，发送按钮禁用。
- 参考图支持添加、缩略图展示和删除；正式规格最多 4 张，单张不超过 10MB，支持 JPG、PNG、WebP。
- 支持智能、21:9、16:9、3:2、4:3、1:1、3:4、2:3、9:16。
- 支持 2K/4K 和 1-8 张结果，实时展示最终输出宽高。
- 深色模式下选中参数使用浅底深字或其他达到可读对比度的方案。
- 发送按钮在浅色、深色、可用和禁用状态均必须清晰可辨；深色可用状态采用品牌青绿底和白色箭头。
- 提交前显示本次预计额度消耗。

### 6.6 任务与图片结果

- 提交后立即插入任务，状态包括排队、生成中、成功、部分成功、失败和取消。
- 成功结果按选择比例展示，不因按钮、标签或加载状态改变布局。
- 点击结果图片打开全屏预览；支持 Esc、点击背景和关闭按钮退出。
- 单图悬停显示下载操作，预览层也提供下载。
- 关闭预览后焦点回到原图片；移动端预览边距不得挤压图片。
- 支持再次生成和修改提示词；原任务和结果不可被覆盖。
- 失败任务保留提示词和参数，显示可理解原因和恢复动作。
- 时间线、侧栏、详情和参数面板隐藏可见滚动条，但仍可滚动。

### 6.7 登录、协议与账户设置

- 登录页提供手机号验证码登录，演示环境验证码为固定测试值，正式环境由服务端发送。
- 登录前必须同意用户协议、隐私政策和 AI 功能使用协议。
- 协议以独立弹窗或新页面打开，内容可滚动、可关闭。
- 登录页桌面端使用高质量动态背景，移动端优先显示表单。
- 登录状态在本地原型中保持；正式环境以安全会话为准。
- 未登录时账户菜单显示“登录”。
- 登录后账户菜单显示“退出登录”，退出后立即恢复“登录”。
- 账户菜单包含平台协议、更新日志、外观、AI 水印、登录/退出和登录后额度区。

### 6.8 额度

- 额度不占用左侧一级导航空间。
- 未登录时不显示额度区；登录后在账户菜单显示。
- 额度区展示剩余值/总量、剩余百分比、进度条和单张预计消耗。
- 大数值使用 `K` 等紧凑格式，不能撑破容器。
- 余额低于等于 30% 使用警告色，低于等于 10% 使用危险色。
- 每次生成完成后更新余额；失败返还规则由正式计费规则决定。
- 额度不足时禁止提交，并展示所需额度、剩余额度和调整方式。

### 6.9 外观与主题

- 支持跟随系统、浅色和深色三种模式。
- 用户选择在本地保存，刷新后不得回到错误主题。
- 跟随系统时监听系统主题变化并即时同步。
- 灵感详情、生成连续画布、输入器、菜单、参数选中态和发送按钮必须分别验证两种主题。
- 登录页背景、图片内容和品牌色不因主题切换失真。

## 7. 核心业务规则

| 规则 | 定义 |
|---|---|
| 登录拦截 | 浏览和编辑草稿公开；产生用户数据或消耗额度的动作需要登录 |
| 意图恢复 | 登录后恢复来源、草稿、参数、参考图和动作，不自动重复提交 |
| 做同款 | 在详情页展开输入器，复制提示词与参数，不带原图片 |
| 用作参考图 | 在详情页展开输入器，复制提示词与参数，并带入原图 |
| 进入生成 | 用户在详情输入器点击发送后进入生成页 |
| 新对话 | 点击时不创建记录，首次提交时创建会话 |
| 会话命名 | 首次提交后截取提示词前 14 个中文字符/28 个英文字符，可重命名 |
| 再次生成 | 使用原任务参数创建新任务，不覆盖旧任务 |
| 修改提示词 | 把原任务内容放回输入器，用户确认后再提交 |
| 参考图删除 | 删除后同步清除草稿引用并重新计算提交状态 |
| 会话删除 | 删除当前会话后切换下一条；无历史时返回空状态 |
| 图片下载 | 详情图和生成结果均支持下载，文件名不得暴露内部存储 Key |
| AI 标识 | 生成图片在展示和下载时遵循显式/隐式 AI 标识策略 |

## 8. 产品数据与指标

- 灵感曝光、分类切换、搜索、搜索历史点击和详情打开。
- 做同款、用作参考图、参考图删除和详情发送。
- 新对话、首次会话创建、会话切换、重命名和删除。
- 任务提交、成功、失败、再次生成、预览和下载。
- 登录拦截、登录成功、退出和意图恢复成功率。
- 从详情复用到任务提交的转化率。
- 生成成功率、平均排队时间、生成时间和额度消耗。

阶段 1 只定义事件和触发点，不实现统计系统。

## 9. 非功能与产品约束

- 使用独立品牌；正式商用前完成图片、字体、提示词和来源授权复核。
- 灵感与生成是唯一普通用户一级业务模块。
- 桌面主要适配 1280px 以上，移动最低支持 360px。
- 所有文字、按钮和图片在桌面与移动视口不得越界、遮挡或不可达。
- 图标按钮提供无障碍名称；不熟悉图标提供 Tooltip。
- 主题对比度、键盘焦点、Esc 关闭和减少动画必须可用。
- 所有后续需求变更通过独立分支和 PR 评审，不直接修改 `main`。
