# 视觉规范

## 1. 设计方向

参考用户提供截图的工作台结构：大面积浅色背景、紧凑左导航、图片优先瀑布流、沉浸式详情和底部自适应生成器。造梦空间使用独立品牌视觉，不复制参考产品的 Logo、渐变和作品素材。

关键词：明亮、克制、专业、安静、图片优先、低干扰。

## 2. 品牌

- 中文名称：造梦空间。
- 英文名称：Dream Space。
- 品牌标记：两个错位的四角星组成抽象“空间入口”，采用实色青绿和深墨色。
- Logo 不使用即梦的彩色飞星轮廓。
- 标题优先使用中文名称；英文仅在登录页、关于信息和品牌锁定组合中出现。

## 3. 色彩

| Token | 色值 | 用途 |
|---|---|---|
| `--color-bg` | `#F7F8F9` | 页面背景 |
| `--color-surface` | `#FFFFFF` | 输入器、弹层、侧栏 |
| `--color-text` | `#17191C` | 主文本 |
| `--color-text-secondary` | `#6F747C` | 次级信息 |
| `--color-border` | `#E5E8EB` | 边框与分隔 |
| `--color-hover` | `#F0F2F3` | 中性悬停 |
| `--color-primary` | `#0E8F7C` | 主操作、焦点和选中 |
| `--color-primary-soft` | `#E7F4F1` | 轻强调背景 |
| `--color-danger` | `#D04444` | 删除与错误 |
| `--color-warning` | `#B26A16` | 额度与警告 |

界面主体使用中性色，品牌青绿只用于选中、提交和关键反馈。演示图片承担更多色彩，避免整页只呈现一个色系。

## 4. 字体

- 中文：系统无衬线字体，优先 `PingFang SC`、`Microsoft YaHei`。
- 英文与数字：`Inter` 或系统无衬线字体。
- 页面标题：24px / 32px，500。
- 区域标题：18px / 26px，500。
- 正文：14px / 22px，400。
- 次级文本：12px / 18px，400，不低于 12px。
- 控件：14px / 20px，500。
- 字间距统一为 0。

## 5. 布局尺寸

### 5.1 桌面端

- 一级导航：72px。
- 生成会话侧栏：280px，可折叠为 0。
- 详情信息栏：420-480px。
- 顶部工具栏：72px。
- 生成页正文最大宽度：1040px。
- 生成器空闲宽度 560-760px、最小高度 72px；编辑态宽度最大 1180px、最小高度 176px，始终位于独立布局行。
- 灵感瀑布流列间距：4px；页面外边距：16px。
- 详情主图与信息栏之间使用 1px 分隔线，不使用浮动卡片。

### 5.2 响应式断点

| 范围 | 规则 |
|---|---|
| `>= 1440px` | 5 列灵感流，完整侧栏和详情信息栏 |
| `1200-1439px` | 4 列灵感流，完整侧栏 |
| `768-1199px` | 3 列灵感流，会话侧栏可折叠，详情信息改抽屉 |
| `< 768px` | 2 列灵感流，底部一级导航，单列生成时间线 |
| `< 420px` | 搜索独占一行，参数菜单横向滚动但不裁切文字 |

## 6. 间距与尺寸

- 基础间距单位：4px。
- 常用间距：4、8、12、16、24、32px。
- 普通按钮高度：36px；图标按钮：36x36px。
- 底部主提交按钮：40x40px 圆形，仅使用箭头图标并带无障碍名称。
- 输入器、菜单和弹窗圆角：8px。
- 图片卡片圆角：0-4px；保持瀑布流的连续性。
- 不使用超大圆角、胶囊式导航和卡片嵌套。

## 7. 图标

- 使用 Lucide 线性图标。
- 常规图标 18px，辅助图标 16px。
- 一级导航选中状态使用对应实心或加粗视觉，但布局尺寸不变化。
- 图标按钮必须有 Tooltip 和无障碍名称。

## 8. 图片表现

- 列表缩略图使用 `object-fit: cover`，容器比例由元数据预占。
- 详情图使用 `object-fit: contain`，背景保持中性浅灰。
- 禁止图片加载完成后改变卡片高度。
- 图片悬停只增加轻遮罩和底部信息，不进行缩放导致布局跳动。
- AI 标识位于图片角落，不能遮挡主要主体。

## 9. 动效

- 悬停和选中：120-160ms。
- 页面区域切换：180-220ms。
- 图片详情切换使用位移和内容替换，不循环播放。
- 生成中仅显示阶段动画，不伪造精确进度。
- 遵守 `prefers-reduced-motion`，关闭非必要动画。

## 10. 页面视觉重点

- 灵感页：图片面积应占首屏 85% 以上。
- 详情页：主图是第一视觉焦点，信息区不使用营销式大标题。
- 生成页：历史内容用于浏览，底部输入器是唯一高强调交互面。
- 登录页：品牌演示图与登录表单并列；移动端隐藏演示图，直接显示表单。

## 11. 导航与弹层

- 桌面一级导航只显示“灵感、生成”，不出现重复“我的”。
- 左下角依次放置额度、通知、分隔线和账户头像；账户菜单向右上方展开，不覆盖主导航按钮。
- 账户菜单包含平台协议、更新日志、外观、AI 水印和登录/退出；图标按钮提供 Tooltip。
- 参数面板桌面最大宽度 520px；移动端左右各留 12px，内容可滚动且所有选项可达。
