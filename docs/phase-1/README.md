## 原型范围

原型覆盖以下页面与跳转：

1. 灵感瀑布流。
2. 灵感作品详情。
3. 生成页与历史会话。
4. 登录页。
5. 做同款、用作参考图、重新生成和登录后恢复意图。

原型使用本地演示数据和高保真灵感素材，只验证产品结构与交互，不代表真实生成模型效果。历史测试已确认：灵感详情默认沉浸式看图，复用后才展开输入器；新对话首次发送后才建立会话；生成结果支持预览与下载；账户菜单承载登录态、额度、语言和外观设置。

## 阶段 1 验证结论

- 核心路径可走通：灵感浏览与搜索、作品详情、做同款、用作参考图、直接生成、结果预览下载。
- 会话具备独立时间线、缩略图、重命名和删除能力；空白新对话不会污染历史列表。
- 浅色、深色和跟随系统主题规则已定义，深色模式参数与发送按钮具备高对比度。
- 灵感内容覆盖人像、摄影、动漫、插画和设计，支持搜索历史及进入页面时的随机排序。
- 后续阶段应优先将原型规则转换为 API 契约、持久化数据模型、任务状态机和真实模型接入验收。
