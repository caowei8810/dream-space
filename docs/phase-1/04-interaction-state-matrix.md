# 交互状态表

## 1. 灵感列表

| 状态 | 触发条件 | 页面表现 | 用户动作/恢复 |
|---|---|---|---|
| 初始加载 | 首次进入 | 顶部可用，瀑布流显示比例骨架 | 自动加载 |
| 正常 | 返回数据 | 图片渐进显示，保留布局空间 | 浏览、搜索、打开详情 |
| 加载更多 | 接近底部 | 末尾追加骨架，不遮挡旧内容 | 自动完成或重试 |
| 空结果 | 搜索无匹配 | 显示搜索词和清空操作 | 清空搜索/切换分类 |
| 请求失败 | 列表接口失败 | 保留顶部，内容区显示错误 | 重新加载 |
| 图片失败 | 单图加载失败 | 原位置显示占位，不改变网格 | 单图重试 |
| 离线 | 网络断开 | 顶部显示非阻塞提示 | 网络恢复后自动重试一次 |

## 2. 灵感详情

| 状态 | 触发条件 | 页面表现 | 用户动作/恢复 |
|---|---|---|---|
| 加载 | 打开作品 | 图片区使用原比例骨架，信息区骨架 | 自动完成 |
| 正常 | 数据完整 | 大图、信息和底部输入器可用 | 复用、点赞、下载 |
| 相邻切换 | 上/下一个 | 保留舞台尺寸，替换内容 | 可继续切换 |
| 末端 | 没有相邻作品 | 对应方向按钮禁用 | 反向切换/关闭 |
| 点赞中 | 点击点赞 | 按钮即时反馈，后台确认 | 失败时回滚并提示 |
| 下载中 | 点击下载 | 按钮显示进行中 | 成功或重试 |
| 登录拦截 | 访客触发保护动作 | 进入登录并保存动作 | 登录后恢复 |
| 作品下架 | 详情返回不可用 | 说明作品不可用 | 返回列表 |

## 3. 参考图上传

| 状态 | 触发条件 | 表现 | 恢复 |
|---|---|---|---|
| 待上传 | 选择文件 | 本地缩略图和进度 | 自动上传 |
| 上传中 | 获取上传凭证后 | 进度环，暂不可提交 | 可取消 |
| 成功 | 服务端确认 | 正常缩略图，可排序删除 | 继续输入 |
| 格式错误 | 非 JPG/PNG/WebP | 不加入列表，明确格式限制 | 重新选择 |
| 体积超限 | 单图大于 10MB | 不上传，显示大小限制 | 压缩后重试 |
| 审核拒绝 | 参考图不合规 | 缩略图被替换为拒绝状态 | 删除/申诉 |
| 网络失败 | 上传中断 | 保留本地项和重试按钮 | 重试/删除 |
| 数量上限 | 已有 4 张 | 上传入口禁用并说明 | 删除后恢复 |

## 4. 生成任务

| 状态 | 进入条件 | 页面表现 | 可用动作 |
|---|---|---|---|
| 草稿 | 未提交 | 输入器保存内容 | 修改、清空、提交 |
| 空闲收起 | 无提示词、无参考图且未聚焦 | 单行紧凑输入器，时间线获得更多可视空间 | 点击或 Tab 聚焦后展开 |
| 编辑展开 | 聚焦、有内容、有参考图或参数面板打开 | 展示完整提示词区与参数工具栏，textarea 随内容增高 | 失焦且内容为空后收起 |
| 参数选择 | 打开参数面板 | 比例、2K/4K、1-8 张及最终像素尺寸完整可达 | 选择即时更新草稿和预计额度 |
| 校验失败 | 内容/参数不合法 | 字段内提示，焦点定位首个问题 | 修改 |
| 额度不足 | 预计消耗大于余额 | 提交禁用，显示所需与剩余 | 调整参数 |
| 提交中 | 创建任务请求中 | 提交按钮锁定，防重复提交 | 等待 |
| 排队 | 任务已创建 | 任务卡显示排队与取消 | 取消 |
| 生成中 | Worker 已执行 | 显示进度或阶段，不显示虚假百分比 | 取消（若支持） |
| 部分成功 | 部分图片成功 | 显示成功图片与失败数量 | 下载成功图、重试失败项 |
| 成功 | 全部图片成功 | 显示结果网格和工具栏 | 下载、复用、再次生成 |
| 失败可重试 | 临时故障 | 保留参数，显示原因 | 再次生成、反馈 |
| 失败不可重试 | 审核/参数拒绝 | 明确下一步，不展示内部规则 | 修改提示词/参考图 |
| 已取消 | 用户或系统取消 | 显示取消和额度结算 | 再次生成 |

## 5. 会话

| 状态 | 页面表现 | 规则 |
|---|---|---|
| 无历史 | 主区显示空白创作状态 | 输入后创建首个会话 |
| 有历史未选中 | 自动选中最近会话 | 可新建会话 |
| 重命名 | 行内输入，Enter 保存，Esc 取消 | 空名称不保存 |
| 删除确认 | 弹窗显示会话名称 | 删除后切换最近会话 |
| 加载失败 | 侧栏错误且主区不清空 | 可重试 |
| 草稿未提交 | 切换时自动保存到会话草稿 | 返回时恢复 |

## 6. 登录

| 状态 | 页面表现 | 恢复 |
|---|---|---|
| 初始 | 手机号、验证码、协议 | 输入信息 |
| 手机号非法 | 输入框内错误 | 修正手机号 |
| 发送中 | 发送按钮锁定 | 请求完成 |
| 倒计时 | 显示剩余秒数 | 到期可重发 |
| 验证码错误/过期 | 验证码字段错误 | 重新输入/发送 |
| 未同意协议 | 登录按钮禁用 | 勾选协议 |
| 登录中 | 页面防重复提交 | 成功或失败 |
| 登录成功 | 恢复来源与草稿 | 执行待恢复动作 |
| 登录失败 | 保留手机号与协议状态 | 重试 |

## 7. 全局反馈规则

- 可在原位置解释的问题使用字段内错误，不使用 Toast 替代。
- 操作成功但不需要用户决定时使用短 Toast。
- 删除、注销等不可逆操作使用确认弹窗。
- 页面级失败必须保留用户已经输入的提示词和已完成上传。
- 禁用按钮必须同时有可见原因，不能只改变颜色。
