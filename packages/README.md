# 共享包目录

`packages` 只承载被多个应用使用，或具有明确跨应用边界的代码。不要因为“以后可能复用”提前拆包。

| 目录        | 唯一职责                                 |
| ----------- | ---------------------------------------- |
| `ui`        | 用户端和管理端共用的无业务基础组件       |
| `contracts` | API 请求、响应、错误码和 SSE 事件类型    |
| `core`      | 纯业务规则、状态机和服务接口             |
| `db`        | Prisma schema、迁移、seed 和数据库客户端 |
| `config`    | 环境变量校验和公共工程配置               |
