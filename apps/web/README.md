# 用户端 Web

普通用户使用的 Next.js 应用。负责灵感浏览、登录、生成会话、任务状态展示和结果下载，不直接访问数据库、队列、对象存储或模型供应商。

## 目录

- `app`：页面路由和布局。
- `components`：跨页面复用的用户端业务组件。
- `lib`：API client、SSE、鉴权和下载等基础适配。
- `stores`：输入器草稿等临时客户端状态。
- `messages`：中英文文案。
- `styles`：全局样式和主题 token。
- `tests`：用户端单元和组件测试。

当前已提供响应式灵感目录、作品详情、账户菜单、协议弹窗和手机号演示登录。账户菜单在登录后读取真实创作额度，展示余额、总量、百分比、进度条及低余额状态；受保护的创作动作会跨刷新保存来源与草稿，登录后恢复但不自动提交。
