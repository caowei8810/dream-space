# 管理端 Web

运营和管理员使用的独立 Next.js 应用。负责灵感内容、用户与额度、任务、审核、模型配置和审计日志界面。

管理端可以根据权限隐藏操作，但 API 必须对每次请求重新执行 RBAC 校验。管理端不得直接连接数据库或模型供应商。

完整的管理端产品需求和功能架构见根目录 [管理端产品需求](../../docs/admin-console-requirements.md) 与 [管理端功能架构](../../docs/admin-console-architecture.md)。ADM-0 至 ADM-4 是当前主线；额度对账属于 ADM-6 的低交互优先级运维能力。

当前已实现独立管理员登录、管理员会话、退出和 RBAC 工作台。任务页通过真实 API 提供状态、模型、日期、关键词筛选、分页和详情抽屉；灵感页提供创建草稿、编辑、发布/下架、来源授权字段与只读审阅角色。

本地默认地址为 [http://localhost:3001](http://localhost:3001)。Mock 模式的演示管理员手机号为 `18800000000`，只读审阅员为 `18800000001`，验证码均为 `123456`。这些数据仅用于本地 seed 和自动验收。

本地可运行 `pnpm admin:smoke` 验证认证隔离、任务查询、灵感 CRUD、公开发布可见性和审阅员写入 403。

当前未实现：工作台、用户管理、管理员角色管理、完整人工审核队列、审核申诉、模型/供应商/路由管理、系统配置和审计日志页面。文档中的目录与接口是后续切片边界，不代表这些功能已交付。
