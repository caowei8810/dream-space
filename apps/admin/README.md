# 管理端 Web

运营和管理员使用的独立 Next.js 应用。负责灵感内容、用户与额度、任务、审核、模型配置和审计日志界面。

管理端可以根据权限隐藏操作，但 API 必须对每次请求重新执行 RBAC 校验。管理端不得直接连接数据库或模型供应商。

完整的管理端产品需求和功能架构见根目录 [管理端产品需求](../../docs/admin-console-requirements.md) 与 [管理端功能架构](../../docs/admin-console-architecture.md)。ADM-0 至 ADM-4 是当前主线；额度对账属于 ADM-6 的低交互优先级运维能力。

当前已实现独立管理员登录、管理员会话、退出和数据库角色权限解析。基础管理提供管理员工号账号列表、邀请创建、编辑、角色分配、激活/停用/撤销和会话撤销；任务页通过真实 API 提供状态、模型、日期、关键词筛选、分页和详情抽屉；灵感页提供创建草稿、编辑、发布/下架、来源授权字段与只读审阅角色。

本地默认地址为 [http://localhost:3001](http://localhost:3001)。Mock 模式的演示管理员手机号为 `18800000000`，只读审阅员为 `18800000001`，验证码均为 `123456`。这些数据仅用于本地 seed 和自动验收。

本地可运行 `pnpm admin:smoke` 验证认证隔离、管理员账号生命周期、会话撤销、任务查询、灵感 CRUD、公开发布可见性和审阅员越权 403。

ADM-0 覆盖管理端壳层、集中权限判断、路由级 403、统一加载/空/错误/404 状态和响应式导航基础设施；ADM-1A 已交付管理员工号账号管理，但角色/权限点 CRUD 和权限矩阵仍属于 ADM-1B。按权限过滤导航只是前端辅助行为，不能视为权限管理功能。后续页面必须继续使用真实 API，不得用前端状态冒充业务成功。

当前已实现用户、角色与权限、风控规则、人工审核/申诉、计费规则、套餐与订单后端、模型/供应商/路由、隐私请求、任务查询、灵感精选和审计日志查询。运营总览从订单与退款账务聚合今日收入；现金钱包、套餐订单和退款仍缺少完整的管理端运营页面，系统配置、告警入口和生产运维能力也尚未完成。
