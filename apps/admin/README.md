# 管理端 Web

运营和管理员使用的独立 Next.js 应用。负责灵感内容、用户与额度、任务、审核、模型配置和审计日志界面。

管理端可以根据权限隐藏操作，但 API 必须对每次请求重新执行 RBAC 校验。管理端不得直接连接数据库或模型供应商。

当前已实现独立管理员登录、管理员会话、退出、工作台导航和生成任务查询。任务页通过真实 API 提供状态、模型、日期、关键词筛选、分页和详情抽屉。

本地默认地址为 [http://localhost:3001](http://localhost:3001)。Mock 模式的演示管理员手机号为 `18800000000`，验证码为 `123456`。这些数据仅用于本地 seed 和自动验收。

当前 B5 下一项工作是灵感创建、编辑、发布/下架及对应的写权限验证。
